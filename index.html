ML Engine
How The Prediction
System Works

Two Kaggle datasets. Four models. 300 trees each. Built to predict your body — not guess it.

1
Data Collection & Merging
Two Kaggle datasets — gym session activity and body fitness metrics — cleaned, deduplicated, and merged on a shared member ID into one labeled dataset.
pd.merge(gym_df, fitness_df, on='member_id')
2
Cleaning & Feature Engineering
Nulls dropped, duplicates removed, columns standardized. BMI calculated from height/weight. Session frequency and weekly caloric averages derived as model inputs.
StandardScaler · dropna · feature_engineering()
3
80/20 Train-Test Split
80% of labeled data trains the models. 20% is held out for evaluation — scored using MAE (average error in real units) and R² (how well the model fits the data).
train_test_split(test_size=0.2, random_state=42)
4
4 Independent Models Trained
One model per target: Calories Burned, Future Weight, Future BMI, Future Fat %. Each runs 300 boosting iterations at a conservative 0.05 learning rate to prevent overfitting.
GradientBoostingRegressor(n_estimators=300, lr=0.05)
5
Rule Engine + ML Output
Workout category assigned via BMI + goal rule table. ML predictions layered on top — producing a complete, personalized fitness prescription and outcome forecast.
BMI_RULES.get((bmi_cat, goal)) → GBR.predict()

Why Not a Classifier?
A classifier achieves only ~25% accuracy on self-selected behavioral gym data — equivalent to random chance across 4 classes. Regression models trained on labeled continuous data deliver measurable, personalized, time-series forecasts.
Supervised Learning Framework
All four models operate under supervised learning — trained on labeled Kaggle data where every input has a known target output. Gradient Boosting is the ensemble algorithm executing within that framework.

ML-Powered Prescriptions
Your Workout.
Engineered By Data.

Gym PRO's rule engine maps your BMI category and fitness goal to a precisely tailored workout plan — then layers ML calorie predictions on top so every session is optimised for your body.

1
BMI + Goal Input
Member's current BMI category (Underweight / Normal / Overweight / Obese) and selected goal (Fat Loss · Muscle Gain · Endurance · Maintenance) are captured on profile setup.
bmi_cat = classify_bmi(weight, height)
2
Deterministic Rule Lookup
A weighted rule table maps every BMI × goal combination to the optimal workout type — HIIT, Strength, Cardio, or Functional — removing the ambiguity of pure ML on behavioural data.
workout = BMI_RULES[(bmi_cat, goal)]
3
ML Calorie Layer
The GradientBoostingRegressor (R² 0.94) predicts exact calories burned for the prescribed session — giving members a real number, not an estimate, before they even start.
predicted_kcal = calorie_model.predict(features)
4
Personalised Plan Delivered
A complete, session-ready workout plan — sets, reps, rest periods, and expected calorie burn — is pushed to the member's dashboard and synced with NutriAI for post-workout nutrition.
dashboard.push(plan, predicted_kcal)
